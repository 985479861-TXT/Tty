# Tty
Tty is a simple terminal emulator *for linux* like konsole and st, it is in only one file thus making it perfect to look at to learn.

# Installation
```bash
git clone https://github.com/985479861-TXT/Tty.git
cd 2
make
```

# Note
run it using ./Tty It is not that useable, meant mainly for learning purposes. It requires it to be used on an *X11 linux* system.
